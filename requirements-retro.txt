# Retro build dependencies: the Windows XP CPython 3.8.20 project publishes
# 32-bit wheels matched to its interpreter. Pillow 11.0.38 is its XP build
# (the version number is the fork's own); PyPI's Pillow 10.4 wheel targets
# newer Windows. cx_Freeze's 5.1-subsystem launcher is what lets the frozen
# executable start on Windows XP; PyInstaller 6's launcher requires Windows
# Vista/7 or newer.
